# TradingView Chip

Используйте **наш публичный проект** https://github.com/evgyur/tradingview-chip . Его исходник уже включён в `vendor/tradingview-chip` на commit `abb651b5627946063f8dbd9931ec1f3ad1180841`. Не клонируйте другой MCP с похожим названием. Лицензия и исходные notices сохранены.

1. Проверьте Node.js 24+. Ничего не устанавливайте глобально без согласия владельца. Для офлайн-дашборда TradingView не обязателен.
2. Прочитайте vendored README, skills/tradingview-chip/SKILL.md и references/setup.md внутри vendor. Сервер и навык — разные части.
3. Если существующее разрешённое подключение работает, используйте его. Иначе согласуйте отдельный браузер: `node vendor/tradingview-chip/src/cli.mjs launch`. В нём пользователь сам входит в TradingView и открывает сохранённый Superchart. Это не перенос текущей сессии. Держите debugger только на loopback; пароль/cookies не извлекайте. В конце закройте только созданный для задачи браузер, не чужие вкладки.
4. Добавьте stdio MCP в текущие настройки Codex: command = фактический Node 24+, args = абсолютный путь к **scripts/tradingview.mjs этого набора**. Этот wrapper принудительно задаёт `TV_READONLY=1`, `TV_ENABLE_GENERIC_UI=0`; мутации не нужны для мастер-класса. `TV_CDP_ENDPOINT` — проверенный literal loopback адрес, обычно `http://127.0.0.1:9222`. `TV_DATA_DIR` — приватная папка ВНЕ этого репозитория. Wrapper откажет в runtime внутри репозитория.
5. Перед правкой конфигурации покажите поля и спросите подтверждение; не перезаписывайте другие подключения. Если есть Codex CLI, он умеет stdio MCP, но синтаксис следует проверить по его `mcp add --help`; не выдумывайте TOML.
6. После нового сеанса выполните browser_list_tabs → выберите фактический target_id → layout_get → chart_get_state. Сверьте тикер, площадку, интервал и наблюдаемый native layout ID. Наличие tools/list не доказывает чтение графика.

Для SBER смотрите MOEX, дневные обычные свечи. Сравните до/после новости отдельно от решения на выбранном срезе; будущие свечи для решения не используйте. История и публичные данные зависят от плана/площадки. При недоступном подключении передайте скриншот; не называйте это успешным MCP.

Шаблон MCP: `examples/tradingview-mcp.json` содержит только placeholders. Не вставляйте его слепо; абсолютные пути индивидуальны. Windows Desktop — отдельная opt-in возможность upstream, а не обязательное требование.
