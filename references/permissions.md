# Разрешения и проверка границ

Владелец runtime — выбранный пользователем Codex, его браузер и терминал. Этот пакет не создаёт облачный хранитель ключей и не меняет владельца системы.

Разрешено после выбора пользователя: чтение публичных источников, создание файлов в выбранном проекте, локальные расчёты; чтение ровно выбранного браузерного графика и брокерского счёта после настройки/согласия. Сохраняйте provenance/time/units и неполное покрытие.

Запрещено по умолчанию: orders/trade/cancel/close/rebalance, transfers/withdrawals/funding/signing, плечо, права, токены, публикация личных данных, новые туннели, открытые debugger-порты, произвольные raw-action wrappers и фоновые расписания. Не делайте даже «тестовый» вызов торгового метода. Конкретная новая финансовая операция требует отдельного точного согласования вне этого учебного пакета.

TradingView wrapper принудительно задаёт TV_READONLY=1 и TV_ENABLE_GENERIC_UI=0; это проверяемая локальная защита только этого сервера. У Альфа/Parallel инструкции не доказывают server-side ограничения: проверьте настоящий endpoint/схемы/права. MCP tools/list и факт наличия токена не являются разрешением на все инструменты.

Секреты остаются в защищённых настройках пользователя, не в URL, командах, логах, чате, Git или HTML. Не копируйте профили/cookies и не отключайте TLS. Начальные файлы с реальным счётом остаются локально; публичный пакет содержит только синтетику.

Отдельно сообщайте: файл подготовлен, конфиг сохранён, инструмент обнаружен, вызов прошёл, данные сверены. Успех предыдущего этапа не доказывает следующий.
