# Поиск Parallel

Официальные источники: https://docs.parallel.ai/integrations/mcp/installation и https://developers.openai.com/codex/mcp/ . Проверьте действующие настройки Codex, не выводя секреты. Если Parallel уже работает, не дублируйте.

Адрес: `https://mcp.parallel.ai/mcp`. Если доступен Codex CLI, команда: `codex mcp add parallel --url https://mcp.parallel.ai/mcp`. Для приложения используйте его текущие настройки MCP; не устанавливайте CLI наугад. Перед изменением покажите diff/поля и получите подтверждение. Остальные MCP сохраните. Без ключа сервис имеет более низкие лимиты; не обещайте безлимитный поиск. Платный ключ вводится только защищённо и отдельно по решению владельца.

Проверка — не запись адреса, а один реальный web_search и чтение исходной страницы. Найдите апрельскую рекомендацию и июньское утверждение дивидендов Сбера за 2024 год. В sber-research.md сохраните даты, сумму на обыкновенную акцию, статус, цитаты и ссылки. Не угадывайте время. Поисковый сниппет не равен прочитанному документу. Отделите новую информацию от уже известной; движение цены проверяется отдельно.

При недоступном поиске можно передать документы. Это рабочий запасной путь, но не доказательство подключённого Parallel. Не добавляйте API-ключи в репозиторий.
