# Альфа PRO MCP: чтение выбранного счёта

Источники: https://alfabank.ru/make-money/investments/pro-terminal/mcp/ и https://alfadt.servicecdn.ru/alfadt/ad5/Alfa-Investments-Pro-MCP.pdf . Это independently authored руководство для публичного набора, не копия частных настроек.

Сначала выясните, где работает уже установленный PRO-терминал и какой интерфейс выбран. Native HTTP MCP может использовать `http://localhost:3367/mcp` на машине терминала, но нужно подтвердить фактическую настройку, а не угадать по примеру. WebSocket router `ws://127.0.0.1:3366/router/` — другой протокол, не MCP. localhost Codex и localhost удалённого терминала — не обязательно одна машина. Новые туннели/сетевые доступы не создавайте по умолчанию.

Владелец вводит токен только в штатную защищённую настройку. Не просите токен в чате, командной строке, HTML или снимке. Если права токена не подтверждены, не называйте его read-only: ограничение действий ассистента не меняет права на стороне брокера.

Перед изменением настроек покажите diff и спросите подтверждение; сохраните другие MCP. После initialize и пагинированного tools/list допустим транспортный smoke get_server_time с пустыми аргументами. Он доказывает только связь. Чтение счёта требует отдельного выбора владельцем.

Для выбранного accountId разрешёнными фактическими схемами прочитайте get_positions, get_balances и нужные спецификации get_stocks/get_equity_participations/get_futures/get_futures_info. Не запрашивайте все счета через null по умолчанию. Не вызывайте ордера, отмены, подписи и произвольные raw-action wrappers.

Сохраните локально {as_of, positions, balances, instruments, futures_info?}: instruments — объединённый массив реально прочитанных спецификаций; futures_info — id → фактический ответ с priceStep/priceStepCost. as_of содержит часовой пояс. Личные имена, номера счетов и ключи в экспорт не включайте.

`python scripts/portfolio_model.py alfa --input alfa-read.json --account-id <выбранный-ID> --balance-group <выбранная-группа> --output moex-current.json`

quantity — штуки акций/паёв или контракты, не лоты. currentBalance уже включает позиции; money повторно не прибавляется. Группы Unified/Papers/Futures нельзя суммировать вслепую. RUB-цены используют currencyId=0. Для фьючерса нужен multiplier=priceStepCost/priceStep. Облигации, опционы и неизвестные валюты помечаются непокрытыми, а не считаются по формуле акции. profitLoss сохраняется как PnL брокера.

Другой брокер требует сопоставления его собственных полей. Если нет разрешённого подключения, продолжите на явно учебном наборе. Работающий JSON-конвертер не является успешным чтением брокера.
