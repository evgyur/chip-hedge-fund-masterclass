# Первый запуск

Работайте в отдельной папке проекта. Скопировать задание → вставить в Codex через Ctrl+V/⌘V → Enter. Продолжайте в одном проекте. Если что-то не получилось, передайте текст ошибки; не перенастраивайте всё с нуля.

Начните с офлайн-примера. `python scripts/workshop.py demo --output <новая-пустая-папка>` копирует шаблон и синтетические данные без сети. Существующие файлы не перезаписываются. На Windows используйте доступный Python 3.10+, например `py -3`.

Затем выберите задачу: проверка новости, чтение графика, расчёт позиции или свой портфель. Для каждой есть отдельная инструкция в корневом SKILL.md. Не подключайте брокера только ради учебного примера. Не просите пользователя отключать защиту или передавать токен в чат.
