# Границы проверки

Публикационные проверки запускаются локально из чистого набора: Python tests, JS-формулы, офлайн demo entrypoint, чтение файлов/ссылок, privacy scan и тесты включённого TradingView source под Node 24+. Фактические результаты перечислены в итоговом ответе автора, а не выводятся из этого списка.

Эти тесты не подтверждают вход в TradingView участника, его тариф/историю и MCP брокера. Для них нужны пользовательский вход, выбранный график/счёт и отдельный реальный readback. Альфа-конвертер проверяется синтетическими примерами структуры из официальной схемы; это не банковский ответ. Parallel требует отдельного live search. Не описывайте весь набор как «всё подключено».

Hosted CI не добавляется; ручные проверки являются основными. Upstream docs внутри vendor — утверждения и предыдущие записи upstream, не новая сертификация нашего устройства или аккаунта.
